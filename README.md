# REKINDLE website

Website for REKINDLE, a project on cascading wildfire disasters funded by the National Science Foundation (awards 2623901, 2623902, 2623903 and 2623904).

The site is plain HTML, CSS and JavaScript and is published with GitHub Pages from the main branch.

News, team members, awards and partner logos are listed in assets/data.js. The home page video is assets/project-video.mp4.
